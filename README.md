# SmartCalc v2.0

Интеллектуальный консольный калькулятор на Python с безопасным разбором
выражений, историей операций, статистикой, памятью и экспортом данных.

## Возможности

- **Базовые операции**: сложение, вычитание, умножение, деление, остаток от деления
- **Вычисление выражений**: `10 + 20 * 3`, `(10 + 20) * 3`, `2 ^ 10`, `sqrt(16)`, `√(16)`, `10 % 3`
- **Умный ввод**: выражение можно ввести прямо в главном меню, без выбора действия, например `1+1`
- **Живой предпросмотр**: результат вычисляется по мере ввода
- **Работа с целыми и дробными числами**
- **Последний результат (ANS)**: `ANS / 4`
- **Память**: M+, M-, MR, MC
- **История операций** с сохранением в `data/history.json`
- **Поиск по истории** (по выражению, операции и результату)
- **Статистика**: количество операций по типам, самая частая операция
- **Экспорт** в TXT / JSON / CSV (в `exports/`)
- **Самодиагностика** (self diagnostics)
- **Логирование** технических событий в `logs/smartcalc.log`
- **Обработка ошибок**: ни один ошибочный ввод не роняет программу
- **Навигация по меню** стрелками вверх/вниз с подтверждением Enter
- **Автоматические тесты** (pytest)

## Точность вычислений

Для всех вычислений используется модуль `decimal`, поэтому результат точен:

```python
Decimal("0.1") + Decimal("0.2")  # 0.3, а не 0.30000000000000004
```

## Безопасность

Выражения разбираются через стандартный модуль `ast` с whitelist разрешённых
конструкций (числа, скобки, `+ - * / % **`, унарные знаки, `sqrt`).
Функция `eval()` не используется, поэтому пользователь не может выполнить
произвольный код внутри приложения.

## Архитектура

Приложение построено по модульной архитектуре с чётким разделением
ответственности:

| Файл | Назначение |
|---|---|
| `main.py` | Запуск приложения, главный цикл |
| `calculator.py` | Математическое ядро на `Decimal` |
| `parser.py` | Безопасный разбор выражений через `ast` |
| `validator.py` | Проверка пользовательского ввода |
| `history.py` | Хранение истории операций (JSON) |
| `statistics.py` | Статистика по истории |
| `memory.py` | Память калькулятора (M+, M-, MR, MC) |
| `exporter.py` | Экспорт в TXT / JSON / CSV |
| `diagnostics.py` | Самодиагностика |
| `logger.py` | Логирование |
| `ui.py` | Интерфейс на базе Rich |
| `tests/` | Автоматические тесты (79 тестов в 8 файлах) |

```

├── main.py            # точка входа
├── calculator.py      # математическое ядро
├── parser.py          # безопасный парсер выражений
├── validator.py       # валидация ввода
├── history.py         # история операций
├── statistics.py      # статистика
├── memory.py          # память
├── exporter.py        # экспорт
├── diagnostics.py     # самодиагностика
├── logger.py          # логирование
├── ui.py              # интерфейс (Rich)
├── tests/             # pytest-тесты
├── data/              # data/history.json
├── logs/              # logs/smartcalc.log
├── exports/           # экспортированные файлы
```

## Требования

- Python 3.9+
- Пакеты из `requirements.txt`

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тестирование

```bash
python -m pytest -v
```

## Использование ИИ

ИИ использовался на этапе разработки для:

1. Генерации функций безопасного преобразования ввода в `Decimal`.
2. Проработки обработки исключений (деление на ноль и др.).
3. Генерации набора unit-тестов для математических функций.
4. Анализа архитектуры и разделения на модули.
5. Поиска потенциальных ошибок и небезопасных мест в парсере выражений.
