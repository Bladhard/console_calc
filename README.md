# SmartCalc v2.0

Интеллектуальный консольный калькулятор на Python.

## Возможности

- ➕➖✖️➗ Базовые операции: сложение, вычитание, умножение, деление
- 🧮 Вычисление выражений: `10 + 20 * 3`, `(10 + 20) * 3`, `2 ^ 10`, `sqrt(16)`, `√(16)`, `10 % 3`
- ⏫ Навигация по меню стрелками ↑/↓ и подтверждение Enter
- ⚡ Умный ввод: выражение можно ввести прямо в главном меню, без выбора действия, например `1+1`
- 🔢 Работа с целыми и дробными числами
- 🧠 Последний результат (ANS): `ANS / 4`
- 💾 Память: M+, M-, MR, MC
- 📜 История операций с сохранением в `data/history.json`
- 🔍 Поиск по истории
- 📊 Статистика: количество операций, самая частая операция
- 📤 Экспорт в TXT / JSON / CSV
- 🧪 Самодиагностика (self diagnostics)
- 🛡️ Обработка ошибок: ни один ошибочный ввод не роняет программу
- 📝 Логирование технических событий в `logs/smartcalc.log`
- 🧪 Автоматические тесты (pytest)

## Точность вычислений

Для всех вычислений используется `Decimal`, поэтому:

```python
Decimal("0.1") + Decimal("0.2")  # 0.3, а не 0.30000000000000004
```

## Безопасность

Выражения разбираются через `ast` с whitelist разрешённых операций
(числа, скобки, `+ - * / % **`, унарные знаки, `sqrt`). `eval()` не
используется, поэтому пользователь не может выполнить произвольный код.

## Архитектура

| Файл | Назначение |
|---|---|
| `main.py` | Запуск приложения, главный цикл |
| `calculator.py` | Математические операции на Decimal |
| `parser.py` | Безопасный разбор выражений |
| `validator.py` | Проверка пользовательского ввода |
| `history.py` | История операций (JSON) |
| `statistics.py` | Статистика по истории |
| `memory.py` | Память калькулятора (M+, M-, MR, MC) |
| `exporter.py` | Экспорт в TXT / JSON / CSV |
| `diagnostics.py` | Самодиагностика |
| `logger.py` | Логирование |
| `ui.py` | Интерфейс (Rich) |
| `tests/` | Автоматические тесты |

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тестирование

```bash
python -m pytest -v
```

## Использование ИИ

ИИ использовался на этапе разработки для:

1. Генерации функций безопасного преобразования ввода в Decimal.
2. Проработки обработки исключений (деление на ноль и др.).
3. Генерации набора unit-тестов для математических функций.
4. Анализа архитектуры и разделения на модули.
5. Поиска потенциальных ошибок и небезопасных мест в парсере выражений.
