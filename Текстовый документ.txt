Кейс 1: Разработка консольного калькулятора с историей операций
Цель: Создать консольное приложение на Python для
выполнения базовых математических операций с сохранением
истории вычислений. Использовать ИИ-инструмент для генерации
кода функций и обработки ошибок.
Задачи:
1. Реализовать функции сложения, вычитания, умножения и деления двух
чисел.
2. Добавить возможность работы с десятичными и целыми числами.
3. Реализовать сохранение истории операций в текстовый файл.
4. Добавить функцию просмотра истории вычислений.
для генерации кода валидации ввода пользователя.
5. Реализовать обработку ошибок (деление на ноль, некорректный ввод).
6. Создать простой интерфейс с меню выбора операций.
Критерии оценки:
•
Корректность математических операций.
•
•
Работоспособность системы истории.
Качество обработки ошибок.
•
Читаемость кода.
